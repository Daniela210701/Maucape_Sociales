Panel de la página

Desde aquí cambias las fotos del inicio, las bodas del portafolio, los paquetes y los datos de contacto. Los cambios se publican solos en 1 o 2 minutos.

Entrar con mi cuenta de GitHub

Se abre el editor (Pages CMS). La primera vez te pedirá autorizar tu cuenta de GitHub y elegir el repositorio Maucape_Sociales; después entras directo.

Otra forma: entrar con clave

Abre este mismo panel con el diseño de Maucape. Necesita una clave de GitHub:

  1. Entra a GitHub → Fine-grained token con la cuenta dueña del repositorio.
  2. En Repository access elige Only select repositories y selecciona Maucape_Sociales.
  3. En Permissions → Contents elige Read and write.
  4. Crea la clave, cópiala y pégala aquí abajo.
